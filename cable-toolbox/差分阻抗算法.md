# 特性阻抗算法（分页）

本页归档“特性阻抗”分页的算法口径与单位规范，涵盖通用说明与各模型的具体公式。当前已实现：模型1·同轴线；其余模型（绞对、微带线、带状线、屏蔽绞对）待补充。

## 通用口径
- 长度单位：mm（除非特别注明）。
- 介电常数 ε：无量纲。
- 日志底数等价：自然对数与十进对数写法严格等价。
  - Z0 = (60/√ε) · ln(X) = (60·ln10/√ε) · log10(X)
  - 常数 60·ln10 ≈ 138.155。行业常用近似“138”→ 约 0.11% 的系统性偏差。
- 显示：前端默认保留两位小数（fmt2），用于工程读数。计算统一采用自然对数实现（60/√ε·ln）。

## 模型1：同轴线（已实现）

### 输入参数
- d（mm）：内部导体“绞合外径”。
- do（mm）：单根导体直径（用于理解/选择 K1，计算公式本身不直接使用）。
- dw（mm）：“有效屏蔽厚度”，单位为 mm（非 ×0.01 mm）。
- D（mm）：绝缘体外径。
- ε（无量纲）：绝缘体介电常数。
- K1（无量纲）：内部导体绞合系数（0.1–1 区间常见），参见对照表。

### 几何等效与约束
- 有效外径：Deff = D + 1.5·dw（单位：mm）。
- 几何约束：Deff > K1·d（否则 Z0 非物理）。

### 计算公式
- 自然对数写法（实现采用）：
  - Z0 = (60/√ε) · ln( Deff / (K1·d) )
- 十进对数等价写法（仅作参考，不作为实现口径）：
  - Z0 = (138.155/√ε) · log10( Deff / (K1·d) )
  - 不使用行业近似“138”，以避免引入约 0.11% 的系统性偏差。

### 验算示例
- 输入：d=0.3，dw=0.05，D=0.72，ε=2.1，K1=0.97。
  - Deff = 0.72 + 1.5×0.05 = 0.795
  - 比值 R = Deff/(K1·d) = 0.795/(0.97×0.3) ≈ 2.7319588
  - 自然对数：Z0 = (60/√2.1)·ln(R) ≈ 41.61 Ω
  - 十进对数精确常数：Z0 = (138.155/√2.1)·log10(R) ≈ 41.61 Ω
  - 十进对数“138”近似：Z0 ≈ 41.565 Ω（与工程表/Excel 常见取法一致）

### 前端实现要点
- dw 按 mm 直接输入与计算（不再乘 0.01）。
- 计算前校验几何约束与正值域；不满足则提示错误信息。
- 摘要卡片同步显示该模型 Z0，主结果区显示自然对数公式结果。
