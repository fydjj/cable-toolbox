GND//缠绕 阻抗（并联，含接触）

- mΩ
算法与公式（展开查看）
外径 D ≈ 1.15 · d · √N（mm）
截面积 A = π · (d/2)² · N（mm²）
A(m²) = A(mm²)/10⁶，ρ(Ω·m) = ρ输入 × 10⁻⁸
单位电阻 r(mΩ/m) = [ ρ / (A(m²) · K) ] × 10³
总电阻 R(mΩ) = [ ρ · L / (A(m²) · K) ] × 10³
接触开：R_out = R + R_c； 关：R_out = R
