# 模型1：同轴线

该模型针对电缆同轴结构，提供以“自然对数”为主的计算口径，并给出与十进对数的严格等价写法。

## 用户输入参数
- 内部导体绞合外径 d（mm）
- 单根导体直径 do（mm）— 用于选择/理解 K1，对公式不直接参与
- 有效屏蔽厚度 dw（mm）— 单位为 mm（注意：不是“×0.01 mm”）
- 绝缘体外径 D（mm）
- 绝缘体介电常数 ε（无量纲）
- 内部导体绞合系数 K1（无量纲）

## 几何等效与约束
- 有效外径：Deff = D + 1.5·dw
- 几何约束：Deff > K1·d

## 计算公式
- 自然对数（实现口径，统一采用）：
  - Z0 = (60/√ε) · ln( Deff / (K1·d) )
- 十进对数（严格等价，仅作参考）：
  - Z0 = (138.155/√ε) · log10( Deff / (K1·d) )
  - 本项目不使用“138”的行业近似常数，以避免约 0.11% 的系统性偏差。

在 Excel 中，可写作：
- = (60/SQRT(ε)) * LN( (D+1.5*dw) / (K1*d) )
- 或（等价参考）= (138.155/SQRT(ε)) * LOG10( (D+1.5*dw) / (K1*d) )

## 输出
- 输出 Z0（单位：Ω）。界面默认保留两位小数显示。

## 验算示例
- 输入：d=0.3，dw=0.05，D=0.72，ε=2.1，K1=0.97
  - Deff = 0.72 + 1.5×0.05 = 0.795
  - R = Deff/(K1·d) = 0.795/(0.97×0.3) ≈ 2.7319588
  - Z0(自然对数) ≈ (60/√2.1)·ln(R) ≈ 41.61 Ω
  - Z0(十进·精确常数) ≈ (138.155/√2.1)·log10(R) ≈ 41.61 Ω
  - Z0(十进·138 近似) ≈ 41.565 Ω
