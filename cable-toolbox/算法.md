# 本次算法要求（当前实现）
- 功能：阻抗计算，分四组：VBUS、GND、内层缠绕、外层缠绕（外层缠绕可选“有/无”，选“无”时不计入计算，仅置灰显示）。每组新增“接触阻抗”输入与开关；默认值：VBUS=10mΩ、GND=10mΩ、内层缠绕=35mΩ，外层缠绕默认关闭。
- 输入参数（每组）：
  - 绞合导体根数 N
  - 单根导体直径 d（mm）
  - 导体长度 L（m）
  - 绞合后线缆根数 K
  - 导体电阻率 ρ（×10⁻⁸ Ω·m）：界面输入为数值×10⁻⁸，计算时换算为 Ω·m
- 中间量与输出：
  - 绞合外径 D（mm）：采用经验系数模型 D ≈ 1.15 · d · √N（本次替代原 D≈d·√N/η 模型）
  - 绞合截面积 A（mm²）：A = π·(d/2)²·N
  - 单位电阻 r（mΩ/m）、总电阻 R（mΩ）：
    - 截面积换算：A(mm²) → A(m²) = A / 10⁶
    - ρ(Ω·m) = ρ输入值 × 10⁻⁸
    - r 与 R 公式：
      - r(mΩ/m) = [ ρ / (A(m²) · K) ] × 10³
      - R(mΩ)   = [ ρ · L / (A(m²) · K) ] × 10³
    - 接触阻抗开关：
      - 开：总电阻 R_out = R + R_c（R_c 为该组接触阻抗，单位 mΩ）
      - 关：R_out = R
- 并联合成规则（第三行展示）：
  - 无外层缠绕：展示并联(GND_out, 内层缠绕_out)
  - 有外层缠绕：关闭“内层/外层缠绕”的接触阻抗输入，新增“缠绕接触阻抗”输入（使用外层卡片上的接触阻抗输入作为该值），展示并联(GND_out, 内层(不含接触), 外层(含统一缠绕接触))
- 说明：目前仅按几何与直流电阻率计算，未计入温度系数、真实绞合填充率等修正。
