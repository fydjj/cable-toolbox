# 本次算法要求（当前实现）
- 功能：阻抗计算，分四组：VBUS、GND、内层缠绕每组新增“接触阻抗”输入与开关；
- 默认值：
	- 1. VBSU单根导体直径 d默认0.08,导体长度 L默认1,绞合后线缆根数 K为1,电阻率 ρ默认1.78,接触阻抗默认10mΩ
	- 2. GND单根导体直径 d默认0.08,导体长度 L默认1,绞合后线缆根数 K为1,电阻率 ρ默认1.78,接触阻抗默认10mΩ
	- 3.缠绕导体直径 d默认0.08,导体长度 L默认1,绞合后线缆根数 K为1,电阻率 ρ默认10.14,  接触阻抗默认35mΩ
- 输入参数（每组）：
  - 绞合导体根数 N
  - 单根导体直径 d（mm）
  - 导体长度 L（m）
  - 绞合后线缆根数 K
  - 导体电阻率 ρ（×10⁻⁸ Ω·m）：界面输入为数值×10⁻⁸，计算时换算为 Ω·m
- 中间量与输出：
  - 绞合外径 D（mm）：采用经验系数模型 D ≈ 1.15 · d · √N（本次替代原 D≈d·√N/η 模型）
  - 绞合截面积 A（mm²）：A = π·(d/2)²·N
  - 单位电阻 r（mΩ/m）、总电阻 R（mΩ）：
    - 截面积换算：A(mm²) → A(m²) = A / 10⁶
    - ρ(Ω·m) = ρ输入值 × 10⁻⁸
    - r 与 R 公式：
      - r(mΩ/m) = [ ρ / (A(m²) · K) ] × 10³
      - R(mΩ)   = [ ρ · L / (A(m²) · K) ] × 10³
    - 接触阻抗开关：
      - 开：总电阻 R_out = R + R_c（R_c 为该组接触阻抗，单位 mΩ）
      - 关：R_out = R
